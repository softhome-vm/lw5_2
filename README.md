# lw5_2 — основной проект (Factory Method)

**Роль в lw5:** консольное приложение «Шоколадная фабрика». Подключает библиотеку **lw5_1** через Composer и содержит всю прикладную логику.

## Что внутри

- `index.php` — точка входа, выбор типа сладости.
- `ClassicChocolateFactory` — создаёт сладости по типу (`cocoa`, `berry`, `caramel`).
- `src/Snacks/` — какао-куб, ягодный батончик, карамельный bite.
- Зависимость `gamer/lw5-library` — пакет из **lw5_1** (библиотека).

## Установка и запуск

```bash
composer install
php index.php
```
